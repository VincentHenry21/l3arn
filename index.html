Assignment Four-Stage Breakdown

Your coursework means managing one complete community project through four distinct operational stages, in this order:

1 · Proposal→2 · Plan→3 · Implement→4 · Evaluate
1
Task 1

Project Proposal

  • Define clear project objectives
  • Set out the project scope, what is in and what is out
  • Build a monitoring and evaluation framework
  • Include quality assurance measures
Merit 1M1: Evaluate community benefits and the positive and negative effects of the project.
2
Task 2

Project Plan

  • Break the work into actionable activities
  • Set target dates and milestones
  • Allocate resources to each activity
  • Carry out a risk assessment
Distinction 2D1: Justify your management and quality control points.
3
Task 3

Implement and Monitor

  • Track progress against the plan as you deliver
  • Keep the project log updated
  • Record risks and issues with mitigation actions
  • Record corrective measures when things change
Distinction 3D1: Include evidence of quality requirements management.
4
Task 4

Project Evaluation

  • Collect stakeholder feedback
  • Compare actual results with the original objectives
  • Formulate reasoned conclusions
Merit 4M1: Evaluate project manager and team performance using feedback.
